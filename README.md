# Movie_Recommendation_System
##Description
This is a Movie Recommendation System that recommends similar movies based on movie name, language and genre provided by the user.

##Technologies used
1.Python
2.KNN(K-Nearest Neighbours(ML Algorithm))
3.ANN(Artificial Neural Network(Deep Learning Algorithm))
4.Tkinter
5.MySQL
6.Scikit-Learn
7.Pandas
8.Numpy

##Features
1.A Movie Recommendation System based on similarity.
2.This is a language , genre and movie name based recommendation 
3.User friendly GUI
